# Руководство по редактированию контента (B&BS)

Этот файл объясняет, где менять данные на сайте без поиска по React-компонентам.

## 1) Где менять телефоны и e-mail

- Файл: `src/config/contacts.ts`
- Здесь находятся:
  - общий e-mail;
  - телефоны по регионам (Польша, Украина, Китай);
  - адреса (Украина, Китай);
  - правило выбора основного телефона по языку.

## 2) Где менять данные компании и статистику

- Файл: `src/config/company.ts`
- Здесь находятся:
  - название бренда;
  - короткое название;
  - подпись копирайта;
  - подтвержденные статистики (17 лет, 275+, 110+, Foshan).

## 3) Где редактировать навигацию и CTA

- Файл: `src/config/navigation.ts`
- Здесь можно менять:
  - названия пунктов меню;
  - ссылки меню;
  - основной CTA в хедере.

## 4) Где редактировать SEO

- Файл: `src/config/seo.ts`
- Здесь меняются:
  - title и description главной страницы по языкам;
  - базовый URL для канонических ссылок.

## 5) Где редактировать услуги

- Файл: `src/content/services.ts`
- Здесь находятся:
  - этапы услуг;
  - карточки услуг;
  - slug для страниц услуг.

## 6) Где редактировать кейсы

- Файл: `src/content/case-studies.ts`
- Для каждого кейса доступны:
  - `id`, `slug`;
  - заголовок и summary;
  - категория;
  - problem / requirements / workCompleted / result;
  - галерея.

## 7) Где менять тексты главной и внутренних страниц

- Основные тексты страниц: `src/content/pages/*.ts`
- Дополнительные layout-данные (блоки, подсказки, формы):
  - `src/content/proces-layout.ts`
  - `src/content/o-nas-layout.ts`
  - `src/content/kontakt-layout.ts`
  - `src/content/my-w-chinach-layout.ts`

## 8) Где хранятся переводы

- Базовая конфигурация языков: `src/i18n/config.ts`
- Логика маршрутов/префиксов: `src/i18n/routing.ts`
- JSON-файлы языков:
  - `src/i18n/messages/pl.json`
  - `src/i18n/messages/uk.json`
  - `src/i18n/messages/ru.json`
  - `src/i18n/messages/de.json`
  - `src/i18n/messages/zh.json`

## 9) Где хранятся изображения

Рекомендуемая структура:

- `public/brand/` — логотипы и бренд-изображения;
- `public/team/` — фото команды;
- `public/china-office/` — фото из Foshan/операций;
- `public/services/` — сервисные изображения;
- `public/industries/` — отрасли;
- `public/cases/` — кейсы.

## 10) Как добавить 6-й язык

1. Добавить код языка в `src/i18n/config.ts` (`locales` и `localeMeta`).
2. Добавить JSON-файл в `src/i18n/messages/`.
3. Добавить подписи в `src/config/navigation.ts` и (при необходимости) `src/config/seo.ts`.
4. Проверить переключатель языка в хедере и мобильном меню.

## 11) Как проверить проект перед деплоем

Выполнить:

1. `npm run lint`
2. `npm run build`

И дополнительно вручную проверить:

- `/pl`, `/uk`, `/ru`, `/de`, `/zh`;
- переключение языка на внутренних страницах;
- формы контакта и консультации;
- калькулятор.

## 12) Юридические данные (обязательно проверить юристом)

- Плейсхолдеры юрданных находятся в `src/config/company.ts` (`legal`).
- Если поле пустое — его нельзя показывать в интерфейсе.
- Тексты privacy/cookies/terms должны пройти отдельную юридическую проверку до публикации.
