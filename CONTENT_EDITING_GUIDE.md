## Услуги {#услуги}

### Список услуг (карточки на главной и странице /uslugi)

**Файл:** `src/content/services.ts`

Каждая услуга имеет поля:
- `id` — внутренний идентификатор
- `title` — название на польском
- `scope` — описание на польском
- `icon` — иконка из lucide-react
- `phase` — фаза: `"pre-production"` | `"logistics"` | `"delivery"`
- `slug` — (опционально) URL для отдельной страницы

### Детальные страницы услуг

Каждая услуга с `slug` имеет свою страницу в:  
`src/content/pages/uslugi-{slug}.ts`

Переводы названий и описаний услуг хранятся в:  
`src/i18n/messages/{язык}.json` — раздел `"services.items"`

## Тексты главной страницы {#главная}

Тексты главной страницы хранятся в файлах переводов:  
`src/i18n/messages/{язык}.json`

Ключевые разделы:
- `"hero"` — заголовок, подзаголовок, CTA кнопки
- `"stats"` — статистика (17 лет, 275+, 110+, Foshan)
- `"trust"` — карточки доверия (5 штук)
- `"services"` — заголовок раздела услуг

**Польский вариант** (`pl.json`) является мастер-копией.

## Переводы {#переводы}

Все переводы хранятся в:

```
src/i18n/messages/
├── pl.json  ← мастер-копия (польский)
├── uk.json  ← украинский
├── ru.json  ← русский
├── de.json  ← немецкий
└── zh.json  ← китайский (упрощённый)
```

**Структура JSON** одинакова во всех файлах. Если добавляете новый ключ в `pl.json`, добавьте его и во все остальные файлы.

**Использование в коде:**
- В клиентских компонентах: `useTranslations("namespace")`
- В серверных компонентах: `getTranslations({ locale, namespace: "..." })`

## Как добавить шестой язык {#новый-язык}

Допустим, вы хотите добавить английский (`en`):

1. **Добавьте локаль в routing:**  
   Файл: `src/i18n/routing.ts`
   ```ts
   export const locales = ["pl", "uk", "ru", "de", "zh", "en"] as const;
   ```

2. **Создайте файл переводов:**  
   Скопируйте `src/i18n/messages/pl.json` → `src/i18n/messages/en.json`  
   Переведите все строки на английский.

3. **Добавьте метку языка в Header:**  
   Файл: `src/components/layout/Header.tsx`  
   Добавьте в объект `localeLabels`:
   ```ts
   en: "English",
   ```

4. **Добавьте контакт для нового языка:**  
   Файл: `src/config/contacts.ts`  
   Добавьте запись в `localeContacts`.

5. **Пересоберите проект** (см. раздел Тестирование).

## Как протестировать проект перед деплоем {#тестирование}

```bash
# 1. Установить зависимости
npm install

# 2. Проверить TypeScript
npx tsc --noEmit

# 3. Проверить линтер
npm run lint

# 4. Собрать продакшн-сборку
npm run build

# 5. Запустить локально
npm start
```

После запуска откройте:
- `http://localhost:3000` — должен перенаправить на `/pl`
- `http://localhost:3000/pl` — польский
- `http://localhost:3000/uk` — украинский
- `http://localhost:3000/ru` — русский
- `http://localhost:3000/de` — немецкий
- `http://localhost:3000/zh` — китайский

Проверьте переключатель языка в шапке и на мобильном.
